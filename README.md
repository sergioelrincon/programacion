# Programación - 1º DAW/DAM (IES El Rincón)

Bienvenido al repositorio oficial del módulo de Programación para el alumnado de primer curso de la doble titulación de los Ciclos Formativos de Grado Superior en Desarrollo de Aplicaciones Web (DAW) y Desarrollo de Aplicaciones Multiplataforma (DAM).

Este espacio está pensado como material de apoyo durante el curso. Aquí encontrarás el código que veamos en clase, ejemplos prácticos y las soluciones a las tareas propuestas.

## Contenido del repositorio

El material de este repositorio se irá actualizando semana a semana e incluye:

*   **Ejemplos de clase:** Código desarrollado durante las explicaciones teóricas y prácticas.
*   **Ejercicios resueltos:** Soluciones a los boletines de ejercicios para que puedas comparar tu enfoque con el código del profesor.
*   **Tareas corregidas:** Versiones finales y óptimas de las tareas evaluables una vez haya pasado el plazo de entrega.
*   **Plantillas base:** Estructuras iniciales de código para comenzar los retos o proyectos de clase.

## Estructura de carpetas

Para facilitar la búsqueda de información, el repositorio está organizado por unidades de trabajo (UT):

*   `/UT01_Fundamentos` - Conceptos básicos, variables y estructuras de control.
*   `/UT02_Orientacion_objetos` - Clases, objetos, métodos y encapsulamiento.
*   `/UT03_Estructuras_datos` - Arrays, ArrayList y mapas.
*   `/Proyectos` - Código correspondiente a los retos intermodulares o proyectos finales.

*(Nota: Esta estructura irá creciendo a medida que avancemos en el temario).*

## Cómo utilizar este repositorio

Como el código se actualizará frecuentemente, la mejor forma de trabajar con este repositorio es clonarlo en tu equipo local mediante Git.

Para obtener el repositorio por primera vez, abre tu terminal y ejecuta:

`git clone [URL_DEL_REPOSITORIO]`

Para descargar las últimas actualizaciones (ejemplos nuevos o tareas resueltas) antes de empezar a estudiar o trabajar, sitúate en la carpeta del repositorio y ejecuta:

`git pull`

## Requisitos técnicos

*   Tener instalado el JDK de Java correspondiente al curso.
*   Un entorno de desarrollo (IDE) configurado.
*   Git instalado en tu sistema.
